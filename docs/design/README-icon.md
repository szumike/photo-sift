# Ikona aplikacji

`app-icon-1f.svg` to źródło (wersja „1f · Czerwień”, viewBox 0 0 100 100, pełny zaokrąglony kwadrat rx 22,5). PNG-i w `PhotoSift/PhotoSift/Assets.xcassets/AppIcon.appiconset/` powstały bez dodatkowych narzędzi. Plik SVG opakowano w płótno 1024 × 1024 (`<g transform="translate(100 100) scale(8.24)">`), tak że korpus ma 824 × 824 px i około 100 px przezroczystego marginesu, zgodnie z siatką ikon macOS. Opakowanie wyrenderował jednorazowy skrypt Swift, który ładuje SVG przez `NSImage` i rysuje go do `NSBitmapImageRep` z przezroczystym tłem (`qlmanage -t` dawał nieprzezroczyste białe tło, więc się nie nadał) do pliku 1024 × 1024. Pozostałe rozmiary (16, 32, 64, 128, 256, 512 px) zmniejszono z niego przez `sips -z`, a rozmiary zweryfikowano przez `sips -g pixelWidth -g pixelHeight`. Pliki @2x to ten sam obraz co sąsiedni rozmiar @1x (np. `icon_16x16@2x.png` = 32 px).
